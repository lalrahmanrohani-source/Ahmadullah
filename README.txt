GitHub Pages upload instructions:
1. Extract this ZIP.
2. Upload/replace ALL files in this folder into the ROOT of your existing GitHub repository.
3. Do not put them inside another folder in the repository.
4. Keep the filenames exactly as shown.
5. Open the website online once, then refresh it. If an old installed shortcut remains, remove it and add the website to the Home screen again.

Files: index.html, manifest.json, sw.js, icon-192.png, icon-512.png, profile-default.jpg.

The provided portrait is the default profile image. A worker's own profile image is still saved locally in that worker's browser and overrides the default only on that device. The original app data key and original application JavaScript were preserved.

Offline use requires the first successful online visit. External services such as WhatsApp still need internet.
